What to take from it

  • Reproduces within half a point. Same seed, but CPU vs GPU kernels are not bit-identical, so a 0.2–0.4 pt gap is expected run-to-run noise, not a bug.
  • “Final” accuracy is really the best checkpoint. The script reloads the best test-set checkpoint before reporting “Final Test Accuracy”, so best and final always match. The genuine last epoch scored 95.45%. Selecting on the test set also inflates the headline number; a validation split would fix both.
  • Test accuracy is noisy. It swings 93.7% → 96.5% → 95.5% while train accuracy climbs steadily — consistent with SGD at lr 0.01. The MTJ scripts use Adam at 1e-3, so the BLIF-vs-MTJ comparison is not like-for-like yet.
  • Sparse activity holds. Layer rates stay at 0.04–0.09, far below the 0.2–0.4 seen in the MTJ models' early logs.
